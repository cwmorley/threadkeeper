# Threadkeeper test corpus

`moonstone-smoke.md` is an original, short, paraphrased smoke fixture based on the public-domain mystery novel *The Moonstone* by Wilkie Collins. The full public-domain source is available from [Project Gutenberg](https://www.gutenberg.org/ebooks/155).

The fixture exists because the execution environment blocked direct network download of the full source. It is deliberately designed to exercise:

- multiple narrators and records;
- a missing object;
- disputed character knowledge;
- conflicting witness accounts;
- an uncertain timeline;
- an investigation;
- a later reinterpretation of earlier scenes;
- a plausible revision scenario.
